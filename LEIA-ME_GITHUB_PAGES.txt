COMO PUBLICAR
1. Extraia este ZIP no computador.
2. Abra a pasta extraída QG_DAS_URNAS_v218_GITHUB_PAGES.
3. Envie o CONTEÚDO da pasta para a raiz do repositório GitHub.
4. O arquivo index.html deve ficar diretamente na raiz do repositório.
5. Mantenha a pasta icons/ com os três arquivos de ícone.
6. GitHub: Settings > Pages > Deploy from a branch > main > /(root) > Save.
7. Após o deploy, faça Ctrl+F5 uma vez para garantir que a versão publicada seja carregada.
