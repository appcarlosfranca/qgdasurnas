QG DAS URNAS v215 — PACOTE COMPLETO PARA GITHUB PAGES

1. Extraia este ZIP no computador.
2. Abra o repositório no GitHub.
3. Na raiz do repositório, substitua os arquivos pelo conteúdo deste pacote.
4. O arquivo index.html precisa ficar diretamente na raiz.
5. Preserve a pasta icons/ com seus três arquivos.
6. Em Settings > Pages, use Deploy from a branch > main > /(root).
7. Após o deploy, faça Ctrl+F5 uma vez para garantir que o novo Service Worker v215 assumiu o cache.
